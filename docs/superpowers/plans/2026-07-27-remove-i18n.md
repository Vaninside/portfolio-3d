# Remove i18n — Inline English Content Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the portfolio from a bilingual (EN/ID) i18n setup to a single-language (English) site by removing the entire i18n layer (provider, hook, context, types, language switcher, both locale JSON files) and inlining English content verbatim into each component.

**Architecture:** Each of the 9 page components (`Hero`, `About`, `Experience`, `Projects`, `Skills`, `Education`, `Organization`, `Contact`, `Navbar`) becomes self-contained — it declares its own typed `const` content at the top of the file and uses inline string literals in JSX. No cross-component content imports. The `I18nProvider` wrapper is removed from `layout.tsx`. All i18n files + dead `public/locales/` are deleted.

**Tech Stack:** Next.js 15 (App Router), React 19, TypeScript, framer-motion, lucide-react, Tailwind CSS. No test framework.

---

## Global Constraints

- All English content is copied **verbatim** from `lib/i18n/locales/en.json`. No rewrites, no "improvements".
- The only exception to verbatim-copy: `Skills.tsx` soft-skills heading — the original calls `t("skills.softSkills.label")` + `t("skills.softSkills.skills")` which don't exist in en.json (softSkills is an array). Current UI renders literal key strings `"skills.softSkills.label skills.softSkills.skills"`. Rewrite hardcodes `"Soft Skills"` as user-approved.
- `About.tsx` reads cross-section keys: `hero.badge`, `hero.ctaContact`, `hero.ctaCv`, `education.gpa`, `education.graduation`, `experience.present`, `about.highlights.projects`. These are inlined in `About` with their exact en.json values.
- `education.gpa` ("GPA: 3.75/4.00") and `education.graduation` ("2024") are **not dead** — `About.tsx:132` and `:144` read them. The `education.items[].gpa` array field (separate) is used by `Education.tsx`.
- No new files/modules for content. Arrays (~200 lines total) live inline in their component files.
- Keep all non-i18n logic untouched: framer-motion animations, refs/effects, event handlers, form validation, 3D tilt cards, `"use client"` directives.
- No test framework. Verification: `npx tsc --noEmit` then `npx next build` then `npm run dev` eyeball.

## Migration Order (build green each step)

1. Rewrite leaf components **one at a time** while `I18nProvider` still wraps the tree (it becomes a harmless no-op once no consumer calls `useTranslation`). Suggested order (smallest → largest to build the pattern):
   `Hero` → `About` → `Experience` → `Projects` → `Skills` → `Education` → `Organization` → `Contact` → `Navbar`
2. Delete `components/ui/LanguageSwitcher.tsx` (Navbar no longer imports it)
3. Edit `app/layout.tsx`: drop `I18nProvider` import + wrapper
4. Delete `lib/i18n/` and `public/locales/`
5. Verify: `npx tsc --noEmit` → `npx next build`
